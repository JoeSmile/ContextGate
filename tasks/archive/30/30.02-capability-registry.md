# 30.02: CapabilityRegistry + 005 migration(后端)

> 阶段: 1a | 依赖: 30.01 | 预计: 1 commit

> 现状: alembic 仅 001-004,无 capabilities 表(验收 P1-1)。

**方案:**
1. `backend/core/capability/registry.py`: `CapabilityRegistry`——**双源注册**:
   - env 静态注册(`CAPABILITY_REGISTRY_JSON`,启动加载,多 worker 一致,只读)
   - DB 动态注册(capabilities 表,启动加载;DB 优先于 env 同名覆盖)
   - `register(spec)` / `get(id)` / `list(kind=, provider=)`
   - 兼容 model_registry: 模型自动映射为 kind=model 的 capability(不破坏现有调用)
2. 新建 `alembic/versions/005_capabilities.py`:
   `id TEXT PK, tenant_id TEXT NOT NULL DEFAULT '*', name TEXT, kind TEXT, provider TEXT,
   spec JSONB, status TEXT DEFAULT 'enabled', cost_model JSONB, permission TEXT,
   created_at TIMESTAMPTZ, updated_at TIMESTAMPTZ`

**修改文件:** `backend/core/capability/registry.py`(新建), `alembic/versions/005_capabilities.py`(新建)
