# 30.11: http 客户端 + authStore(4 槽位)(前端)

> 阶段: 1b | 依赖: 30.10 | 预计: 1 commit

> 现状: 无。后端认证 X-API-Key。**P0 安全: key 存 sessionStorage,不用 localStorage。**

**方案:**
1. `src/api/http.ts`: fetch 封装
   - 自动加 `X-API-Key`(从 authStore 读,未登录跳 /login)
   - `ApiError { code, status, message }`;401 → 清 key 跳登录
   - 403 → 结构化 `{forbidden: true, needed: "xxx"}`(供 30.14 高亮)
   - `apiGet/apiPost` 泛型封装,供 react-query 使用
2. `src/stores/authStore.ts`: zustand + persist(**sessionStorage**)
   - **4 槽位**: user / tenant_admin / auditor / super_admin 各存一个 key,独立存储互不覆盖(Pitfall 17)
   - `activeRole` + `setKey(role, key)` + `switchRole(role)` + `clear`
   - 生产演进 TODO: httpOnly 会话 cookie(前端只存"已认证"标记),不阻塞本轮
   - 登录页: 填 key → 调 `GET /health` 验证(无 /api 前缀)→ 存对应槽位

**修改文件:** `frontend/src/api/http.ts`, `frontend/src/stores/authStore.ts`
